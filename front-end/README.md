## Statuts

- **fait** : source primaire (doc officielle, données caniuse ou web-features, blogue d'équipe) ou mesure ;
- **inférence** : notre déduction ;
- **non-verifie** : moins de trois sources indépendantes trouvées.

## En une phrase

La vraie séparation de 2026 n'est pas « moderne contre ancien ». C'est le site-vitrine d'agence (3D, récit au défilement, primé) contre le site-produit sérieux (calme, rapide, texte net, mouvement court). Une petite entreprise relève du second, et ce qui la rend moderne se passe surtout sous l'interface. **Inférence.**
